# Кадр — установщики и обновления

Здесь публикуются Windows-установщики и файлы автоматического обновления программы «Кадр — архив сотрудников».

Исходный код основной программы находится в закрытом репозитории. Этот репозиторий содержит только минимальную оболочку, которая открывает опубликованную программу и проверяет новые версии.
